# TrackIt: архитектура

## Назначение

TrackIt собирает данные о правках в редакторе VS Code, накапливает их по часам и показывает статистику: по периодам, файлам, папкам и времени суток.

## Выбор IDE

Выбрана Visual Studio Code. Её API расширений позволяет подписаться на изменения документов, добавить элемент в строку состояния и показать пользовательскую панель (webview). Расширения пишутся на TypeScript.

## Модули

| Модуль | Ответственность |
| --- | --- |
| extension.ts | Создаёт модули, связывает их, регистрирует команды |
| ChangeTracker | Получает изменения текста, считает добавленные и удалённые строки |
| FolderSelector | Хранит список отслеживаемых папок, проверяет принадлежность файла |
| Storage | Держит агрегаты в памяти, сохраняет их в JSON с отложенной записью |
| Aggregator | Превращает агрегаты в сводку: итоги, по дням, часам, файлам, папкам, тепловая карта |
| time | Формат дат, день недели, начало периода |
| StatusBar | Показывает число строк за сегодня |
| StatsPanel | Открывает панель, передаёт в неё готовую сводку, обновляет её |
| media/stats.js | Рисует графики Chart.js и тепловую карту |

## Структуры данных

Основное хранилище — объект `Record<string, BucketStats>`. Ключ имеет вид `YYYY-MM-DD|HH|путь к файлу`, значение содержит суммы за этот час по этому файлу:

- `added` — добавлено строк;
- `removed` — удалено строк;
- `edits` — число правок.

Такая схема позволяет получать любые срезы простым суммированием: по дню, по часу суток, по дню недели, по файлу или по папке. Отдельные записи для каждого нажатия клавиши не сохраняются.

Файл на диске имеет формат `{ version: 1, buckets: {...} }`. Номер версии нужен, чтобы при смене формата можно было корректно читать старые данные.

## Агрегация

`parseRows` разбирает ключи и отбрасывает строки вне выбранного периода и вне отслеживаемых папок. `summarize` проходит по строкам один раз и заполняет:

- итоги и чистый прирост (добавлено минус удалено);
- массив по дням, отсортированный по дате;
- массив из 24 значений по часам суток;
- матрицу 7 × 24 для тепловой карты (строки — Пн..Вс, столбцы — часы);
- топ-15 файлов и топ-15 папок по числу добавленных строк.

## Хранение

Данные записываются в `trackit-data.json` в папке `globalStorageUri`. Запись откладывается на 2 секунды, чтобы серия правок давала одну операцию записи. При выгрузке расширения данные сохраняются немедленно.

## Панель статистики

Панель создаётся один раз. Расчёты выполняет расширение, webview только отображает готовую сводку. Обмен сообщениями:

- webview → расширение: `ready` (готов к приёму данных), `period` (выбран период);
- расширение → webview: `data` (сводка для отрисовки).

Обновления после правок объединяются таймером на 1 секунду, чтобы не перерисовывать панель на каждое нажатие.

## Решения и ограничения

- Метрика продуктивности не используется: плагин только считает строки, интерпретацию оставляет пользователю.
- Строка считается по переносу (Enter). Это простой и однозначный критерий, но он не различает написанный код и вставленный текст.
- Графики Chart.js подключаются из CDN, поэтому для панели нужен интернет.
- Тесты не написаны. Проверка выполнялась вручную в окне Extension Development Host.
