# TrackIt

Плагин для VS Code, который считает добавленные строки кода и показывает статистику по времени, файлам и папкам.

## Возможности

- Подсчёт добавленных и удалённых строк. Новая строка появляется при нажатии Enter.
- Счётчик «N стр. сегодня» в строке состояния.
- Панель статистики с периодами: сегодня, неделя, месяц, всё время.
- Графики по дням, по часам суток, по файлам и по папкам.
- Тепловая карта «день недели × час», которая показывает, когда вы обычно пишете код.
- Выбор отслеживаемых папок. По умолчанию учитываются открытые папки проекта.
- Сброс накопленной статистики.

## Установка

1. Соберите пакет: `npx @vscode/vsce package --allow-missing-repository --skip-license`.
2. Установите полученный файл `trackit-0.1.0.vsix` через «Install from VSIX...» в панели расширений.

Для разработки можно запустить плагин из исходников: откройте папку проекта в VS Code, нажмите F5 и работайте во втором окне.

## Команды

| Команда | Что делает |
| --- | --- |
| TrackIt: Открыть статистику | Открывает панель с графиками |
| TrackIt: Выбрать отслеживаемые папки | Показывает список папок с отметками и кнопку добавления папки с диска |
| TrackIt: Сбросить данные | Удаляет всю накопленную статистику после подтверждения |

## Настройки

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| trackit.folders | [] | Абсолютные пути папок для учёта. Если список пуст, учитываются открытые папки |
| trackit.showStatusBar | true | Показывать счётчик за сегодня в строке состояния |

## Где хранятся данные

Статистика хранится в файле `trackit-data.json` в папке хранилища расширения VS Code. Данные не отправляются в интернет и остаются на вашем компьютере.

## Ограничения

- Считаются переносы строк, а не символы. Набор текста без Enter не меняет счётчик.
- Вставка большого блока считается по числу переносов внутри блока.
- Для графиков нужен интернет: Chart.js загружается с cdn.jsdelivr.net.
- Статистика хранится отдельно на каждом компьютере.
