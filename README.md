# TrackIt

Расширение для VS Code, которое считает добавленные и удалённые строки кода и показывает статистику по времени, файлам и папкам.

## Описание

TrackIt следит за правками в открытых документах. Когда в тексте появляется или исчезает перенос строки, счётчик обновляется. Данные копятся по часам, поэтому их можно сворачивать по дням, часам суток, дням недели, файлам и папкам.

## **Структура**

- `package.json` — манифест расширения: команды, настройки и параметры сборки
- `src/` — исходный код расширения
- `docs/ARCHITECTURE.md` — архитектура, модули и структуры данных
- `README.md` — описание проекта

## Возможности

- Подсчёт добавленных и удалённых строк. Строка считается появившейся при нажатии Enter.
- Счётчик «N стр. сегодня» в строке состояния.
- Панель статистики с периодами: сегодня, неделя, месяц, всё время.
- Графики по дням, по часам суток, по файлам и по папкам (по 15 лидерам).
- Тепловая карта «день недели × час», которая показывает, когда вы обычно пишете код.
- Выбор отслеживаемых папок. По умолчанию учитываются папки открытого проекта.
- Сброс накопленной статистики с подтверждением.

## Установка

Сборка пакета из исходников:

```
npx @vscode/vsce package --allow-missing-repository --skip-license
```

Полученный файл `trackit-0.1.0.vsix` ставится через панель расширений (Install from VSIX).

## Команды

| Команда | Действие |
| --- | --- |
| TrackIt: Открыть статистику | Открывает панель с графиками |
| TrackIt: Выбрать отслеживаемые папки | Список папок с отметками и кнопка добавления папки с диска |
| TrackIt: Сбросить данные | Удаляет всю статистику после подтверждения |

## Настройки

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| trackit.folders | [] | Абсолютные пути папок для учёта. Если список пуст, учитываются открытые папки |
| trackit.showStatusBar | true | Показывать счётчик за сегодня в строке состояния |

## Где хранятся данные

Статистика записывается в файл `trackit-data.json` в папке хранилища расширения VS Code. Данные не передаются на сторонние серверы и остаются на вашем компьютере. Единственный сетевой запрос делает панель статистики: она загружает библиотеку Chart.js с cdn.jsdelivr.net.

## Ограничения

- Учитываются переносы строк, а не символы. Набор текста без Enter счётчик не меняет.
- Вставка большого блока считается по числу переносов внутри него.
- Графики требуют интернета, так как Chart.js загружается из CDN.
- Статистика хранится отдельно на каждом компьютере.
- Автоматических тестов нет. Проверка выполнялась вручную в окне Extension Development Host.
